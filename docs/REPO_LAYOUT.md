# Struktura repozitáře

Do kořenového adresáře projektu `C:\alma\katalogizacni-listky` běžně patří:

- `manifest.json`
- `package.json`
- `package-lock.json`
- `README.md`
- `LICENSE`
- `CHANGELOG.md`
- `SECURITY.md`
- `PRIVACY.md`
- `.gitignore`
- `.gitattributes`
- `.editorconfig`
- složka `cloudapp`
- složka `docs`

Soubory s VELKÝMI PÍSMENY jsou běžná dokumentace GitHub repozitáře.
CloudApp je při běhu nepoužívá. Nepatří do `cloudapp/src`, ale do kořene projektu
nebo do `docs/`.

V této verzi jsou pracovní návody (`GITHUB_PUBLISH.md`, `EXLIBRIS_SUBMISSION.md`,
`TESTING.md`, `RELEASE_CHECKLIST.md`) uklizené do `docs/`.
