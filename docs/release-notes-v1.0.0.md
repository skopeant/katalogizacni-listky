# Katalogizační lístky v1.0.0

Initial production release.

## Features

- Enter one or more local Alma MMS IDs.
- Retrieve BIB records through the Cloud App REST service.
- Build catalog-card text from MARC21 bibliographic fields.
- Prefer Czech `czenas` subject headings.
- Display multiple subject headings vertically.
- Preview generated catalog cards in the Cloud App.
- Print three cards per A4 page.
- Read-only operation: no Alma data is modified.
- Custom KL application icon.
- Availability restricted to institution `420CARDS_CVUT`.

## Tested

- Real Alma bibliographic records.
- Normal librarian account without Alma administrator privileges.
- Browser print workflow.
